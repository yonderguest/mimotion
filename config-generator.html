mimotion 配置生成器

在这个页面填信息，然后把生成的内容复制到 GitHub Secrets / Variables。页面不会上传你的账号密码，所有内容只在当前浏览器里生成。

1. 填信息 填 Zepp Life 账号、密码和步数范围。
2. 点生成配置 右侧会出现要复制到 GitHub 的内容。
3. 去 GitHub 填写 表格里的名称填到 Name，右边的值填到 Secret 或 Value。

填写信息

如果你是在 GitHub 页面里看到满屏代码，说明打开方式不对。请用 README 里的“在线打开配置生成器”链接，或者把本文件下载到电脑后双击打开。
多个账号用 # 分隔，例如 a@example.com#b@example.com。
多个密码也用 # 分隔，顺序要和账号一致。
只有 fixed 模式会用到。
这是运行结果的微信通知，不是微信步数同步。留空就不会推送通知。

复制到 GitHub

填写仓库地址后，这里会显示快捷入口。
新手只需要看“Secrets”和“Variables”两张表。每一行都要在 GitHub 里单独新增一次：左边填 Name，右边填 Secret 或 Value。高级模式 CONFIG 可以先不用管。

新手模式：Secrets

打开 GitHub 的 Secrets 页面，点 New repository secret。名称填左列，Secret 填右列。
